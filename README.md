# Christian

**Open the Book. See the story. Meet Jesus.**

Evangelical interactive 3D Bible: the whole Protestant canon as a flippable book on a table, using the public-domain World English Bible. The plan — locked stack, full-text pagination, page-turn behavior, and study overlays as annotations — is in [PLAN.md](PLAN.md). Tone and guardrails are in [PRODUCT.md](PRODUCT.md).
